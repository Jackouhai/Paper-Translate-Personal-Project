Docker demo checklist

Thứ tự kiểm tra an toàn trước khi public một demo Compose trên VPS.

1. Phân loại port

  • Public: frontend hoặc reverse proxy, ví dụ 3000:80.
  • Internal: web-api, parse-api, vLLM; gọi nhau bằng tên service.
  • Local-only: port cần truy cập từ host để debug, bind vào 127.0.0.1.

2. Chuỗi healthcheck

translate-gemma / paddle-ocr-vl → parse-api → web-api → web-frontend.

Container phụ thuộc chỉ khởi động sau khi dependency đạt healthy.

3. Lệnh kiểm tra

docker compose config --quiet
docker compose ps
docker compose logs --tail=100 web-api
nvidia-smi
docker run --rm --gpus all nvidia/cuda:12.8.1-cudnn-runtime-ubuntu22.04 nvidia-smi
ss -ltnp

4. Checklist trước public

  • Chỉ frontend/reverse proxy có port public.
  • Model ports không bind ra Internet.
  • Image và tunnel không dùng tag mutable như latest.
  • Đã kiểm tra VRAM với đúng profile của GPU.
  • Đã biết cách xem log và dừng tunnel.
  • Đã có kế hoạch xoá job/output cũ và giới hạn log.
