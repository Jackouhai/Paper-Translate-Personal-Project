VPS preflight

Chạy các lệnh này trên VPS trước khi build PP-DocLayout:

uname -a
nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv,noheader
docker --version
docker compose version
docker info --format '{{json .Runtimes}}'
df -h /
free -h

docker run --rm --gpus all \
  nvidia/cuda:12.8.1-cudnn-runtime-ubuntu22.04 nvidia-smi

Pass criteria

  • nvidia-smi trên host hiển thị GPU, VRAM và driver.
  • docker compose version chạy được.
  • Container CUDA hiển thị cùng GPU khi dùng --gpus all.
  • Còn đủ disk cho image, model cache và output PDF.
