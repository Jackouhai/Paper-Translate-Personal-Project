Bài 2 · VPS preflight

Kiểm tra VPS trước khi build image nặng, để tránh tốn thời gian và dung lượng cho một máy không chạy được GPU container.

Mục tiêu bài này: xác nhận Docker, NVIDIA GPU pass-through, dung lượng đĩa và RAM. Tất cả lệnh bên dưới chỉ đọc thông tin; chưa build image và chưa khởi động service.

1. Kiểm tra hệ điều hành và tài nguyên

uname -a
nvidia-smi --query-gpu=name,memory.total,driver_version --format=csv,noheader
docker --version
docker compose version
docker info --format '{{json .Runtimes}}'
df -h /
free -h

2. Kiểm tra GPU có đi được vào container

Đây là kiểm tra quan trọng nhất. Nó tách lỗi “host chưa cài NVIDIA Container Toolkit” khỏi lỗi build hoặc lỗi model.

docker run --rm --gpus all \
  nvidia/cuda:12.8.1-cudnn-runtime-ubuntu22.04 nvidia-smi

3. Cách đọc kết quả

  • GPU/VRAM: profile VPS hiện tại nhắm tới RTX 3060 12 GB. Máy ít VRAM hơn cần profile nhẹ và có thể chạy từng stage.
  • Driver: phải được host nhận qua nvidia-smi; container không tự sửa driver host.
  • Docker Compose: phải có lệnh docker compose, không chỉ có Docker Engine.
  • Runtimes: JSON nên có runtime NVIDIA hoặc Docker phải chấp nhận cờ --gpus all.
  • Disk/RAM: model cache và Docker layers có thể chiếm nhiều GB; ghi lại số còn trống trước khi build.

Bài tập gửi lại

Chạy trên VPS thật rồi gửi kết quả theo mẫu này. Có thể che hostname/IP; đừng gửi token hay file .env có secret.

GPU:
VRAM:
NVIDIA driver:
Docker:
Docker Compose:
GPU container test: PASS/FAIL
Disk free:
RAM:
Error (if any):

Sau kết quả này, ta sẽ đi theo một trong ba nhánh: máy đạt chuẩn để build; VRAM thấp cần profile tiết kiệm; hoặc sửa NVIDIA Container Toolkit trước.
