Bài 1 · Docker demo trên VPS

Ranh giới mạng: internal khác public như thế nào?

Mục tiêu: sau bài này bạn tự đọc được phần ports trong Compose và biết service nào được phép lộ ra Internet.

1. Ý tưởng cốt lõi

Compose tự tạo một network nội bộ. Các container trong network đó gọi nhau bằng tên service, ví dụ web-api gọi http://translate-gemma:8001/v1. Không cần publish port ra host cho việc này.

Ngược lại, ports: "8001:8001" nghĩa là port 8001 của container được đưa ra port 8001 trên host. Nếu host là VPS public, port đó có thể bị Internet truy cập — tùy firewall.

Quy tắc nhớ: service-to-service dùng tên service; chỉ publish thứ mà người dùng bên ngoài thật sự cần.

Nguồn: Docker Networking in Compose.

2. Vẽ demo hiện tại

Internet / browser │ ▼ chỉ nên vào frontend web-frontend :80 ← host :3000 │ internal network ▼ web-api :8083 ├── parse-api :8082 │ └── paddle-ocr-vl :8000 └── translate-gemma :8001

Trong sơ đồ, các port 8083, 8082, 8000, 8001 là đường nội bộ giữa container. Port 3000 mới là điểm vào cho browser trong demo local. Trên VPS có tunnel, tunnel nên trỏ vào web-frontend, không trỏ thẳng vào model server.

3. Đọc Compose bằng một câu hỏi

Mở compose.yaml và với mỗi ports:, hỏi:

  1. Ai cần truy cập port này: browser, host để debug, hay container khác?
  2. Nếu là container khác, có thể bỏ ports và dùng tên service không?
  3. Nếu host cần debug, có thể bind 127.0.0.1 không?

Ví dụ an toàn hơn cho model server:

ports:
  - "127.0.0.1:8001:8001"

Hoặc nếu không cần gọi từ host:

# bỏ toàn bộ ports của translate-gemma
# web-api vẫn gọi được:
# http://translate-gemma:8001/v1

4. Thực hành 5 phút

  1. Chạy docker compose config --quiet. Không có output và exit code 0 nghĩa là Compose parse được.
  2. Chạy docker compose config, tìm tất cả dòng ports:.
  3. Ghi ra giấy 3 cột: port, ai cần, public hay internal.
  4. Chạy ss -ltnp trên VPS để xem host đang lắng nghe port nào.

Đừng sửa file ngay. Trước tiên hãy gửi lại bảng phân loại của bạn; đó là bước kiểm tra hiểu bài.

5. Tự kiểm tra

Hãy trả lời bằng đúng ba dòng theo mẫu này:

3000: ...
8000: ...
8001: ...

Trong mỗi dòng, điền public hoặc internal và một lý do ngắn. Không cần nhớ thuật ngữ khác.
